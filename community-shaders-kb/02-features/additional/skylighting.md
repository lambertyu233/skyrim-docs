# Skylighting 天光遮蔽

> 分类：附加特性 · 状态：已发布（Nexus 版本 1.2.3，支持 SE / AE / VR）

模拟**大规模的世界空间环境光遮蔽**。它属于**全局光照（GI）**这个极难的领域。

效果是：**建筑下方、密林之中**出现柔和的**环境阴影**，在没有直射光的地方增强对比与真实感。官方称它是「我们做过的所有功能里**最具变革性的一个**」，且**并非沿用现成技术，而是从零自研**。

## 与 ENB 的同名功能完全不同

| | ENB Skylighting | CS Skylighting |
|---|---|---|
| 实现基础 | 用 **shadow map** | 自研，不依赖阴影贴图 |
| 有效性 | **只在正午与午夜前后才正常工作**。其它时间会坏掉——会在斜角把一切遮蔽，导致 ENB 预设不得不在日出日落时**关掉 skylighting**（否则整张地图变黑） | 全天有效 |
| 方向 | **只从一个方向**做 | **从各个方向**做 |
| 开销 | 每帧都要算，很贵 | 把计算量**分摊到多帧**，代价是可能出现偶发的帧时间波动（官方说未来可能分摊得更好） |

## 连带影响（重要）

Skylighting 深度接入了 CS 的其它部分：

- **Wetness 湿润**：**有遮蔽的地方会保持干燥**——所以**屋檐下不会有积水**。未来可能用于积雪/结霜效果。
- **Dynamic Cubemaps**：Skylighting 判定物体何时被天空遮挡，从而**阻止动态立方体贴图在不应出现天空反射的地方渲染天空反射**。
- **水**：反射同样改善，并且**额外获得体积环境光照明**。
- **特效**：雾与烟也会吃到 skylighting，因此**不会在黑暗里发亮**。

## 算法（官方说明）

**一句话**：以快照方式**实时渐进烘焙可见性探针**，用光栅化的单向射线。

**展开**：大约以 **30 帧/秒**的速率，渐进地对来自不同光照方向的阴影取平均，近似出「环境光被周围物体遮挡了多少」，并把信息以**球谐（spherical harmonics）**的形式存进一个大致以相机为中心的网格里。这些遮蔽信息随后可（随机地）插值，用于**大规模环境光遮蔽**以及**去掉屋顶下的湿润**。

> 不需要降噪。但如果开了 TAA / FSR / DLSS，时空蓝噪声（spatio-temporal blue noise）会抖动 skylighting，让它**免费地被模糊掉**。

## 常见问题（官方 FAQ）

**和 SSGI 有什么不同？**

- SSGI 里的 AO 是**更小尺度、屏幕空间、动态**的。
- Skylighting 的 AO **尺度更大**，**不依赖屏幕内信息**，**不随相机移动而变化**。只有**静态**物体（房屋、树木、地形等）能遮挡；**动态物体只能接收遮蔽**。
- 另外 skylighting 能影响**透明物体和水**，并且**在室内会被禁用**（室内没有天空）。
- **官方建议两者一起用**，再加上 SSGI 提供的间接光（IL），才是完整效果。

## 安装与需求

1. 安装 Community Shaders 及其全部前置。
2. **把本 MOD 装在它下面。**
3. （可选）安装 [SSGI](ssgi.md)。本 MOD 是为配合 SSGI 设计的，但**并不强制**。

## 兼容性

- **与一切兼容。**
- 移动或开关物体可能引发问题。官方说**目前没有已知问题**，但这是可能性之一；Skylighting 会**尽量不为动态物体渲染遮蔽**并持续更新来缓解。

## 性能提示

低端机可考虑移除（官方 FAQ 把它列为「低端可移除」的候选之一）。请用 [Profiling](../../04-development/testing-and-debugging.md) 实测，而不是凭印象。
