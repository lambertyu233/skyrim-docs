# Image Based Lighting 基于图像光照

> 分类：核心特性 · 状态：已发布

用立方体贴图球谐推导的物理化 IBL 替换游戏环境光。

## 说明

以 cubemap 球谐（spherical harmonics）推导的基于图像光照替换原版环境光，提升整体光照一致性与真实感。
