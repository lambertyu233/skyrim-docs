## character-appearance-kb 百科化改写（48/48 完成）

用户要求：把 character-appearance-kb 做成百科全书式的详尽知识库，
每条都能看清 mod/功能的**前世今生**与**安装使用方法**。

### 做法

- 先跑取证（WebSearch）拿到一批**一手**材料，写成共享简报给各分组执行 agent 用，
  避免每个 agent 各自猜作者/年份导致编造。这是本次质量的关键。
- 9 组并行 subagent 按分类重写，主控统一跑 build_index / validate_kb /
  check_index_ui / check_links / build_workspace_index / sync_scripts --check。
- 并行 agent **不能**跑 build_index.py（会互相覆盖产物），这点必须在 prompt 里写死。

### 统一骨架（已写进 README + CONTRIBUTING）

`速览（信息卡+要点）/ 前世今生（时间线）/ 它解决什么问题 / 安装 / 使用与配置 /
兼容与冲突 / 排错 / 取舍与建议 / 来源`；
排错类条目改用 `速览/前世今生/成因(按频率)/排查顺序/修法/判断分叉点(别误诊)/来源`。
