## 可复用经验

- `build-maintainable-kb` 技能的 `build_index.py` 从 **`manifest.json` 的嵌套 `kb.name`** 读标题；写成扁平 `name` 会静默退化成默认标题"资料库"，不报错 —— 建完库必须 grep `<title>` 复核。
- 技能自带的 `build_index.py`（新版）与 `community-shaders-kb/scripts/build_index.py`（旧版）**不是同一份**：旧版把分类标签硬编码在脚本里，新版从 manifest 的 `categories[].dir/title` 读。**新建库用技能里的那份**。
- 本机 Bash 的 PATH 依旧损坏，脚本前需 `export PATH="/usr/bin:/bin:$PATH"`；建库流程本身可全程用 `Write` 工具 + 托管 Python 完成。
