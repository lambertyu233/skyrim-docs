    证据：`Parsing.cpp::StripReplacerPath`（注释写明 strip 两层子目录）、

  - **本机 1920 mod 实测**：49 个 OAR 根 / **8 种插入点**（`animations\` 后 32、`Meshes\` 根 1、
    `character\` 后 1 = Live Action、`_1stperson\animations\` 后 2、dragon/horse 各 1、
    大写变体 11）；419 个 submod；submod 内 hkx 首段分布 `animations` 1749 / 根下 1520 /
    `Actors` 892 / `female` 242 / `male` 41。
  - `_variants_<原文件名去扩展名>` 变体目录（官方原文 + `ConvertVariantsPath` 双向印证）；
    `.mohidden` 现为**子串**匹配且跳过整棵子树；`overrideAnimationsFolder` 的基准目录是
    **submod 的父目录**（`<Mod>\`）而非 submod 内。
  - Legacy（DAR）两型：`_CustomConditions\<数字>\` + `_conditions.txt`（priority = 目录名）；
    `<插件名.esp>\<FormID 十六进制>\`（priority 恒 0，自动生成 `IsActorBase`）。
