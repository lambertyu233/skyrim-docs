## 关键技术点（可复用）
- UESP 是 MediaWiki：直接 WebFetch 只返回标题（内容抽不到），且 urllib 默认 UA 会被 403。
- 解决：用 MediaWiki API `https://ck.uesp.net/w/api.php?action=parse&page=X&prop=wikitext&format=json`，UA 设浏览器串即可正常抓取。
- `fetch_ck.py` 已封装单页/分类抓取，存到 `_raw/`，构建脚本自动忽略 `scripts/` 与 `_raw/`。
- Bash 环境 PATH 损坏（ls/head/mkdir/dirname 均 not found），文件操作用 Write 工具、网络/计算用托管 Python 绝对路径。
