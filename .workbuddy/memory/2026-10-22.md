### 核实到的硬事实（写库前必须先核实，别照抄 wiki）
- **主答案**：`Data/SKSE/Plugins/CommunityShaders/SettingsUser.json`。
- **4 层合并优先级**（源码注释原文 `LOADING ORDER: Default → User → Overrides → User Overrides`）：
  `SettingsDefault.json` < `SettingsUser.json` < `Overrides/*.json` < `Overrides/User/<特性>.user.json`。
  → **Overrides 优先级高于用户设置**，这是"调完重启还原"的第二大原因（第一是没点 Save Settings）。
- **CS 退出时不自动保存**：`State::Save()` 的调用点只有菜单的 `Save Settings` 按钮
  （`MenuHeaderRenderer.cpp`）+ 首次引导完成时强制落盘一次。改完直接退 → 丢。
- **版本命名分界**：0.8.x = `CommunityShaders.json` / `CommunityShadersUSER.json` /
  `CommunityShadersTEST.json`，在 `Data\SKSE\Plugins\` **根下**；
  **1.0.0 起**改名 `Settings*.json` 并移入 `Data\SKSE\Plugins\CommunityShaders\` **子夹**。
  1.0 改名时**旧文件不自动迁移**，且新版 JSON 结构分层了（Menu/Advanced/General/
  Replace Original Shaders/Disable at Boot/各特性节）。
- 其它文件各自职责：`SettingsTheme.json`+`Themes\`（1.5.0+）、`AppliedOverrides.json`（1.4.0+）、
  `SceneSettings\InteriorOnly.json`（1.5.0+，目前仅"仅室内"一种）、
  `CommunityShaders_ImGui.ini`（**在 Plugins 根下，只存 ImGui 窗口几何，不存着色器参数**）、
  `Data\Shaders\Features\<特性名>.ini`（装没装/版本，不是用户参数）、`Translations\`（1.7.0+）。
- Override 文件命名：`<Mod名>_<特性名>.json`，全局用 `<Mod名>_Global.json`。
- 日志：`Documents\My Games\Skyrim Special Edition\SKSE\CommunityShaders.log`
  （文件名由 `Plugin::NAME` + `.log` 生成，目录是 CommonLibSSE 标准 SKSE 日志目录）。
