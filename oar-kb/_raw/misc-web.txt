--- 回帖 (MTB) —— 本库引用的核心规律 ---
> the OAR gui doesn't seem to allow adding a child condition to isfemale
That is because the parent condition should be the OR, with all options being children of the OR
condition. If PC is female then that condition should already apply (can see that in the GUI, just
select the player in the console and it will show you which conditions hold); is nothing overriding
it (for specifically the PC)? (If you want it for male PC add an OR above with above and the condition
spoonsinger mentioned below it.)

--- 楼主最终解法（2025-02-12） ---
I found a solution using Dynamic Random Female Idle Animations
Simply placing the idles from the Gunslicer mod into the "basicidle" folder of DRFIA works!
With both mods installed everyone applicable is using the idles.

【本库注】楼主最终并未在 OAR 条件层面解决，而是绕道另一个 mod。因此只采信该帖的
「条件结构规律」与「真实 config.json 字段样本」，不要采信它的结论。

Animations: GTS uses Nemesis as its behavior engine and Open Animation Replacer (OAR) to dynamically
replace animations. [...]

Changing Animations in OAR
You can tweak conditions, priority of the animations and even disable some animations you don't
like/want by using its menu. To access it, press Shift + O while in game. In the menu, you can filter
the mod/animation's folder name or look for the folder number and check under "Legacy"(for mods that
were made using Dynamic Animation Replacer structure).

Example on how to search and tweak/disable certain idles using OAR:
Select your character/NPC with console; Press Shift + O to open OAR;
Click on "Animation Log", at the bottom, to enable the logger.
Now "play" the animation you want to disable or tweak. If it's an attack animation, attack. If it's a
jump animation, jump. And so on. Note down the folder number/name appearing in the Logger.
Example using the Running animation for First person: Filter for 98999 (Folder number/name found
previously); Use User mode; Disable/tweak the animation folder and save

[4] Nexus mod 93359 — DAR to OAR Converter
    https://www.nexusmods.com/skyrimspecialedition/mods/93359
    allycat1031 and V3kta | v1.0.8 (2023-06-14)

What it does
This tool can convert DAR mods to the new OAR structure. It copies all the files from the
DynamicAnimationReplacer folder to the OpenAnimationReplacer folder, then generates the JSON files
needed at each level.
To keep things simple, the numbered folders of DAR are preserved, which also makes determining priority
in config generation much easier.

How to use
- Select the root folder of the DAR mod you want to convert (the folder where the meshes folder are located).
- After selecting the DAR mod, you can customize the OAR output folder and/or the OAR Mod name used in
  the OAR project config.json
- Click Convert.

What is planned
- better UI / fixing bugs / full fledged editor feature

【事实对照】
- 目录是 Data\Meshes\...\OpenAnimationReplacer\<Mod>\<Submod>\，没有 Data\OAR\ 或 Data\OAR.json
- OAR 没有控制台命令；入口是 Shift + O
- 动画文件是 .hkx，不是 .kf / .nif / .fbx
- OAR 没有热刷新快捷键；运行时不能物理增删动画文件，改动只在重启后生效
- 当前版本 3.2.1，从未有 5.0；首发日期 2023-06-01，2019 年不存在 OAR
- 没有 State Override 功能；OAR 不编辑 Animation Graph 节点树
