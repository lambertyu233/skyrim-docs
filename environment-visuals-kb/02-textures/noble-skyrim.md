# Noble Skyrim（HD-2K）

- **作者**：Shutt3r（一手源：Nexus 21423；二手源：howtovideogame 2026 榜单）
- **Nexus**：skyrimspecialedition/mods/**21423**（SE 版 2018-11-24 上传，
  最终 v5.5.0，2018-12-03；LE 原版在 skyrim/mods/45807）；
  当前 70,418 endorsements（一手源：Nexus 21423）
- **分辨率**：HD-2K 主线；另有 **performance FullPack**（室外多降至 1K、
  "主"纹理仍 2K，一手源：21423 readme）

## 定位

Noble 是**风格统一导向**的整合包：建筑为主线，延伸到风景、地牢、矿洞、
洞穴与杂物。与 Skyland（扫描写实）相比，Noble 更"手绘、统一、略暗"——
社区常把它当作**混搭底座**（base），上面叠其它包的局部覆盖
（一手源：Skyland AIO 页"use it as a base or to overwrite whatever base you
use like Noble"）。

## 停更的影响

- 贴图 mod **不含插件逻辑**，不受游戏 1.6.x→1.7.x 升级影响
  （社区经验，与 2026 年榜单"texture-only mod is not affected by game patches"
  的表述一致）。
- 停更意味着新区域/新 DLC 内容无覆盖，与新世界的接缝需自己接受。

## 常见搭配（社区经验）

- Noble + SMIM + 单点高质量包（CleverCharff 城市系列、RUSTIC 系列）。
- STEP 指南历史上用 Noble 作为多个材质 mod 的覆盖基准（一手源：STEP wiki）。
