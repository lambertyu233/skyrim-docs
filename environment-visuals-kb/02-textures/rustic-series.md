# RUSTIC 系列（fadingsignal / Gamwich）

## ⚠️ 作者归属（高频错误）

**RUSTIC 不是单一作者**：

| 子系列 | 作者 | 证据 |
|---|---|---|
| RUSTIC Windows / RUSTIC Clothing 等早期单品 | **fadingsignal** | Nexus 各页 + moddingskyrim 作者名录（一手源） |
| RUSTIC Clutter Collection / RUSTIC Soulgems / RUSTIC Cooking | **Gamwich**（Soulgems 与 Saerileth 合作） | SETOG 指南原文 "RUSTIC CLUTTER COLLECTION - Special Edition by Gamwich"、"RUSTIC SOULGEMS - Special Edition by Gamwich and Saerileth"（一手源：Nexus 5883） |
| RUGNAROK（地毯，常与 RUSTIC 并列推荐） | Gamwich | 同上 |

中文二手文章常把整个 RUSTIC 系列归给 fadingsignal 或笼统写"某工作室"——都是错的。

## 代表页

- RUSTIC Windows SE = skyrimspecialedition/mods/17923（fadingsignal）
- RUSTIC Clutter Collection SE = Gamwich（Nexus 搜索 "RUSTIC Clutter"）
- RUSTIC Soulgems SE = Gamwich and Saerileth

## 生态位

"**单点高质量替换**"的代表：每个 mod 只做一件事（窗、衣服、灵魂石、炊具），
独立版本管理。适合逐项雕琢、不喜欢一体化包风格的玩家。

## 版本注意

RUSTIC 系列多为 2017-2018 年 SE 版，之后停更；贴图 mod 不受游戏版本影响，
但 AE/新 Creation Club 内容无覆盖。
