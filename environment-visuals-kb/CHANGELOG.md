# CHANGELOG

## 1.0.0（2026-10-22）

- 初版建库，**53 条目 / 11 分类**。
- 事实基础：七轮可信来源调研——Nexus 发布页描述/文件页/更新日志、作者论坛回帖、STEP Modifications Wiki、Modding.wiki、IGN/Epicube 等对作者名单的整理（仅作线索，全部回 Nexus 文件信息页核实）。
- 已核实并记录的关键事实：各主流 mod 的作者归属与 Nexus ID（见 `10-sources/author-attribution-corrections.md`）；Skyrim 202X = 原 Skyrim 2020 Parallax 的 SE 现行页（2347，v10.5.2）；RW2 SE = 2182；Cathedral Weathers = 24791；MM = 11052（T4GTR34UM3R）；HLT = 50961；NGIO = 42161（已支持 1.7.99/1.7.104）；DynDOLOD = 32382；CAO = 23316。
- 已纠正一批流传错误：Water for ENB 作者是 mindflux 而非 paganmetalfan；Folkvangr 是 Grumbledoook 而非 SimonMagin；Skyrim 3D Trees and Plants 是 mathy79 而非 Pfuscher；RUSTIC 的 Clutter/Soulgems 系是 Gamwich+Saerileth 而非 fadingsignal；"SE 必配 ENBoost" 与 STEP 结论相反。
- 版本敏感性：NGIO 1.6.11+ 确认适配游戏 1.7.x；SMIM/Noble/ELFX 等停更于 2018-2019 但贴图不受游戏版本影响（已在条目注明）。
