# Enhanced Lights and FX（anamorfus）

- **作者**：**anamorfus**（一手源：Nexus 2424 + PS4 移植页 Credits）
- **Nexus**：skyrimspecialedition/mods/2424；当前 **v3.06**（2019），
  217k endorsements
- **权限严格**：禁止转载（含 Bethesda.net）、修改与资产使用需授权
  （一手源：发布页）

## 模块（均一手源：发布页）

| 插件 | 作用 |
|---|---|
| EnhancedLightsandFX.esp | 主模块：所有光源发光（含室内窗户）、新蜡烛烟 FX、新水反射、市摊/帝国帐篷半透明、每旅店按当地天气配色、昼夜差强化、酒馆更暗更烟 |
| ELFXEnhancer.esp | 室内/地牢压暗、雾色与距离调整、降色调（去"白"灯）、动态环境光模板 |
| ELFX - Hardcore.esp | 含 Enhancer 全部 + 非人居区域极暗 |
| ELFX - Exteriors.esp | 室外光位与 FX：大城市建筑窗外新着色器、裂谷灯笼 bug 修正、桥/船假阴影、去掉"不照亮地形"旗标、加"Never fades" |
| ELFX - Weathers.esp | 天气光照调色：更大的太阳与新纹理、更密的雨与雷声、浓雾仅见数米、夜更暗且随天气变化 |
| Enhanced Ice | 浮冰与冻湖着色器 |

## 兼容性（一手源：发布页）

- 主模块：兼容任何不改光/FX/其网格的 mod；**其网格必须覆盖对方**。
- Enhancer：兼容任何不改 imagespace 与光照模板的 mod。
- Weathers：兼容任何不改天气的 mod；与 CoT 理论兼容但**不推荐**
  （CoT 天气太多，ELFX 的天气很少被轮到）。
- 与雪 mod 有专门兼容（3.05 为 Better Dynamic Snow 调过网格）。

## 现状（社区经验）

v3.06 后停更；现代配置更多用 **Lux 系**（见[室内光照 mods](interior-lighting-mods.md)）
或 Community Shaders 的 Light Limit Fix；ELFX 的遗留价值在其
**大量兼容补丁生态**与"去无源光"的经典调光哲学。
