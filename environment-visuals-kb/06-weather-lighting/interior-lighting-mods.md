# 室内光照 mods（Lux 系 / Embers XD / RLO / ELE）

## Lux 系（GGUNIT）

- **主条目**：Nexus 搜 "Lux"（GGUNIT）；资源与补丁：
  **Lux Via** = skyrimspecialedition/mods/**63588**（作者页 Credits 可见
  其与 SMIM/HLT/路灯/中世纪灯笼等大量联动，一手源）
- **哲学（一手源：发布页转述）**："if there is a light source, there is
  light, and where there is none, expect darkness"——**手工逐个重打**
  全境室内光，比原版"平铺照亮"更电影感；**专为 ENB 用户设计**。
- **硬性依赖**：Lux Via 资源 + Lux patch hub（发布页 Requirements）。
- 家族含 **Lux Orbis**（室内体积光/光柱）等。

## Embers XD（mindflux）

- **作者**：mindflux（同 Water for ENB、Particle Patch）
- **定位**：**Embers HD 的继任者**（装 XD 前先卸 HD，一手源：榜单转述）；
  重制营火等火源。
- **特性**：无脚本 → 随时安全装卸；提供 **lite 2K/1K** 版给低显存；
  **不与其它改火的 mod 共存**；2026-09 仍有更新（二手源：howtovideogame）。

## 老将指针（一手源：巴哈姆特整理帖）

- **Realistic Lighting Overhaul SSE（RLO）**：sydney666。
- **ELE - Eternal Existence Lighting / (ELE)**：--JawZ--。
  两者是 ELFX 时代的替代品，现多被 Lux 系取代。

## 搭配注意（一手源混合）

- Lux 与 ELFX **同功能冲突**（都改室内光）——二选一。
- 202X 页面明说 "ELFX, let Skyrim 2020 overwrite ELFX. Also compatible
  with Lux"（一手源：Nexus 2347）。
- Lux Via Credits 显示其与 HLT、MM Real Lantern、medieval lanterns、
  SDlutz 路灯替换等**同一盏灯的竞争关系**——装灯类 mod 逐个试覆盖。
