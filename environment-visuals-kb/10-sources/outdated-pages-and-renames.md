# 过时与改名页面指南

## 头部案例：Skyrim 2020 Parallax → Skyrim 202X

- 中文教程高频写"**Skyrim 2020 Parallax**"并指向 SE 页——
  实际 SE 现行页面是 **"Skyrim 202X by Pfuscher"（Nexus 2347）**，
  当前 v10.5.2（2025-07）。
- 旧 SE 页（2777）与 LE 页/LE 移植页（112824，badcozmad 移植）仍存在，
  但**内容已并入 202X 体系**。找不着旧名不是被下架，是改名+重组。
- 连带变更：视差网格改按区域发布（Whiterun / Riften Ground），
  地形视差拆 "Complex Terrain Parallax"。

| mod | 最后更新 | 影响 |
|---|---|---|

| Noble Skyrim 5.5.0 | 2018-12 | 同上；AE 新内容无覆盖 |
| ELFX 3.06 | 2019 | 同上；权限严格 |
| Terrain LOD Redone 1.42 | — | 贴图类，可用 |
| Pure Waters | LE 时代 | 已被 RW2/WFE 取代 |
| RUSTIC 系列 | 2017-2018 | 同上 |
| SFO 2.74a | **2024-11（仍在更）** | 别当它停更了 |

## 找页面的正确姿势（社区经验）

1. **用 Nexus 站内搜索 + 作者名**，不要用百度/Google 找"Nexus 页面"
   （镜像站会排在前面）。
2. 认 **Nexus ID**（本库各条目 source 字段已给）。
3. 看 **Files 页的 "Last updated"** 判断活跃度，别看发布页缓存。
