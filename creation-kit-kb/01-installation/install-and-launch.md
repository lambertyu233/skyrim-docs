# 获取与启动 Creation Kit

Creation Kit 对拥有 PC 版《天际》与 Steam 账号的用户**免费**提供，通过 Steam 分发与更新。

## 安装步骤

1. 打开 **Steam 客户端**，进入 **库（Library）**。
2. 在库顶部分类切换到 **工具（Tools）**。
3. 找到 **Creation Kit**，双击安装。
4. 安装完成后，在工具列表中启动即可。

直接启动链接（经典版）：
`steam://run/202480`

## 版本差异

| 游戏版本 | Creation Kit 商店应用 |
| --- | --- |
| Skyrim（经典版 / Legendary） | `202480` |
| Skyrim Special Edition（SE） | `1946180` |

> 注：Anniversary Edition 沿用 SE 的 Creation Kit。

## 首次启动

- 首次启动会要求选择要加载的 **主文件（.esm）** 与已启用的插件（.esp）。
- 建议先只加载官方主文件（`Skyrim.esm` 或 `SkyrimSE.esm`）熟悉界面，再逐步加入自己的 MOD。
