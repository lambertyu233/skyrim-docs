# 快捷键映射（渲染窗口）

下表为在 **Render Window（渲染窗口）** 中常用的快捷键。完整列表见官方页面。

> ⚠️ 与以往工具不同，Creation Kit **不允许**用户自定义热键映射，窗口中相关选项已被移除。

## 常用快捷键

| 功能 | 按键 | 说明 |
| --- | --- | --- |
| 锚定相机 | `SHIFT+F` | 基于当前选择锚定相机 |
| 清除选择 | `D` | 取消当前选中 |
| 复制选择 | `CTRL+C` | 复制当前选中 |
| 剪切选择 | `CTRL+X` | 剪切（CTRL+V 粘贴） |
| 删除选择 | `DELETE` | 删除当前选中 |
| 放到地面 | `F` | 落到最近碰撞面 |
| 复制选择（副本） | `CTRL+D` | 复制并自动选中副本 |
| 旋转模式 | `W` | 切换旋转 Gizmo |
| 缩放模式 | `2` | 切换缩放 Gizmo |
| 选择模式 | `R` | 隐藏所有 Gizmo |
| 循环相机视角 | `Y` | 切换不同相机视角 |
| 循环选中物体可见性 | `1` | 普通 / 透明 / 隐藏 间切换 |
| 编辑地形 | `H` | 打开地形编辑器 |
| 编辑 Navmesh | `CTRL+E` | 切换 Navmesh 编辑模式 |
| 创建 Multibound | `CTRL+B` | 为选中物体创建包围盒 |
| 落下相机 | `ALT+Z` | 相机落到选中物体底部 |

## 提示

- Navmesh 编辑另有专属快捷键，见 [Navmesh Cheat Sheet](https://ck.uesp.net/wiki/Navmesh_Cheat_Sheet)。
- 脚本编辑器内也有编辑快捷键，但属于文本编辑范畴。
