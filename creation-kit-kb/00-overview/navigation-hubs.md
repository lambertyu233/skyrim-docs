# 导航枢纽（五大板块）

UESP Creation Kit Wiki 的首页将全部内容归入 **五大核心枢纽**，按读者意图组织。本资料库的分类目录即映射自这五大枢纽，并补充了「概览」与「安装」两层。

## 五大枢纽

| 枢纽 | 用途 | 本资料库对应目录 |
| --- | --- | --- |
| **Tutorials**（教程） | 新手入口，按工作流的手把手实操指引 | `06-tutorials` |
| **Game Systems**（游戏系统） | 任务、对话、AI、魔法等游戏机制参考 | `03-game-systems` |
| **Editor Reference**（编辑器参考） | 「这个按钮是干嘛的？」——界面与编辑器功能 | `02-features` |
| **Scripting Reference / Papyrus**（脚本参考） | 全新脚本语言 Papyrus 的语言与 API 参考 | `04-scripting` |
| **SKSE Plugin Development**（SKSE 插件开发） | 用 C++ 扩展引擎（Skyrim Script Extender） | `05-tools` |

## 入门建议

- **完全新手**：从 `06-tutorials` 的「Creation Kit 界面教程」与「基础任务脚本」入手。
- **想了解某个游戏系统**：进入 `03-game-systems`。
- **想知道某个编辑器按钮/窗口**：进入 `02-features`。
- **要写脚本**：进入 `04-scripting`（先读语言概览，再读函数/事件参考）。
- **要做引擎级扩展**：进入 `05-tools` 的 SKSE 插件开发。

## 安装提示（首页 SteamTip）

> 如何安装并启动 Creation Kit？
> 在 Steam 库 → 工具 中找到 Creation Kit。经典版商店应用 `202480`；特别版（SE）商店应用 `1946180`。
