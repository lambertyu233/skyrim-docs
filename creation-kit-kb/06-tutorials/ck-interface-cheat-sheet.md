# Creation Kit 界面速查表

一页式速查，编辑时随手对照。完整说明见[编辑器界面](../02-features/editor-interface.md)与[快捷键映射](../02-features/keyboard-mapping.md)。

## 窗口速查

| 窗口 | 打开/定位方式 | 用途 |
| --- | --- | --- |
| Object Window | 菜单 View → Object Window | 浏览/搜索所有 Form |
| Cell View | 菜单 View → Cell View | 选择/进入 Cell 与 Worldspace |
| Render Window | 默认打开 | 3D 编辑主视口 |
| Reference / Properties | 双击选中物体 | 编辑引用属性 |
| Landscape | 快捷键 `H` | 地形编辑 |
| Navmesh | 快捷键 `CTRL+E` | 导航网格编辑 |
| Preview | 默认面板 | 选中物体预览 |

## 常用操作

- **放置物体**：Object Window 拖入 Render Window。
- **选择 / 取消**：`D` 清除选择。
- **复制 / 删除**：`CTRL+D` 复制、`DELETE` 删除。
- **Gizmo 切换**：`W` 旋转、`2` 缩放、`R` 选择模式。
- **落到地面**：`F`。

## 提示

- 找不到窗口时，用菜单 **View** 重新调出。
- Navmesh 专属快捷键见 [Navmesh Cheat Sheet](https://ck.uesp.net/wiki/Navmesh_Cheat_Sheet)。
