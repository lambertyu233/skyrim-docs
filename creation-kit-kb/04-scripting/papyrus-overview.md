# Papyrus 脚本概览

**Papyrus** 是 Creation Kit 内置的**全新脚本系统**，用于驱动游戏逻辑。它是一个完整的脚本语言，初次接触可能需要时间，但学会后可迁移到其它编程语言。

## 它是门户（Portal）

Papyrus 参考页是所有相关内容的入口，按经验水平提供不同路径：

- **完全新手**：先读 [Papyrus 语言要素](papyrus-language.md)，再跟 [Hello, World 教程](https://ck.uesp.net/wiki/Bethesda_Tutorial_Papyrus_Hello_World)。
- **资深 Bethesda MODder**（做过 Morrowind/Oblivion/Fallout）：术语大体保留，但接口与概念全新，务必先看[与旧脚本的差异](https://ck.uesp.net/wiki/Differences_from_Previous_Scripting)。
- **有经验的程序员**：直接看 [Papyrus 语言要素](papyrus-language.md) 概览。
- **专家**：把本页当作函数索引，用浏览器 `Ctrl+F` 速查。

## Papyrus 索引（核心板块）

- **概念**：语言要素、变量与属性、语句、数组、状态（States）、函数、扩展脚本、线程、持久化、存档笔记。
- **实战**：官方脚本教程系列、差异说明、完整示例、社区教程、排错 FAQ。
- **参考**：语言参考、脚本对象、关键字、编译器参考、编译器/运行时错误、INI 设置、控制台命令、术语表。
