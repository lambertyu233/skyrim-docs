# HIMBO（Highly Improved Male Body Overhaul）

> **一句话**：HIMBO 是男性侧的"人台"——与女性 CBBE 同一思想的高模男性身体替换，
> 带全身滑块与 BodySlide/RaceMenu 支持；它**不自带皮肤纹理、不含私密处网格**，
> 两者都要靠另外的 mod 补上。只装女性身形不装男性身形，
> 是"男性角色还是原版方块手"的最常见原因。

| 许可证 | 主体网格与内衣网格 **CC-BY-SA-4.0**；**允许搬到 Bethesda.net，前提是不改 mod 名字**（Nexus 权限栏，经搬运者转引） |

要点：

- **HIMBO 是男性生态位上的 CBBE**：身体只提供网格 + 滑块体系，形状由你用 BodySlide 构建；
  护甲必须找 **HIMBO 版**，否则角色退回原版体型（作者描述原话精神）。
- **v4.0 是分水岭**：Novelyst 重做了 UV，此后 HIMBO 与 SOS 纹理全面互通——
  "男性皮肤要下 SOS 版"这条经验的根源就在这里。
- **默认预构建网格是 SOS（裸露）版**（带裆部开口）；想要 Nevernude（四角裤）版，
  用 BodySlide 自己构建对应选项即可（作者描述）。
- **HIMBO Zero for OBody**：作者专门为零化基础（OBody / BodyGen 要求）准备的预设。
- 男性链与女性链**相互独立**：HIMBO 可与 CBBE / 3BA / BHUNP / UBE 并存，互不覆盖。

### 它从哪来

HIMBO 的直接灵感来自 **SAM**：SAM 用 Samuel（胖）/ Samson（肌肉）等全身滑块
塑造男性体型，Kreiste 把这套思路搬到了 BodySlide 体系里，并明确以 CBBE 为精神样板。
它的网格底子也站在前人肩上：Nexus credits 致谢 **FavoredSoul、Chris57、Ratrace、
Honkman**（Better Males Remesh）与 **zzjay**（High Poly Hands）。

它要解决的问题很具体：SOS/SAM 生态里，VectorPlexus 对权限极其严格、
文件托管也不稳（社区一贯抱怨），而"BodySlide 化 + 开放许可"的男性身体长期缺位。

### 中间经历了什么

真正的转折是 **v4.0 与 Novelyst 的合作**：重写 UV 映射，使任何 SOS 时代的
纹理 mod、schlong addon、手脚替换都能无缝用在 HIMBO 上。此后 HIMBO 从
"SOS 的附属"变成"SOS 的功能性替代"，也是从这一版起，社区指南开始普遍建议
**男性皮肤下 SOS-Lite 版**。

### 现状

仍在维护、持续被新 mod 支持：新盔甲普遍带 HIMBO 的 Bodyslide 文件
（一手证据见 [ube.md](ube.md) 引用的 Iron Rose Armor 发布页）。
它与女性身形的关系**不是竞争而是并行**——男女两条链可以同时启用。

## 它解决什么问题

**没有它之前**：男性角色只有原版方块身；想美化靠 Better Males / SAM / SOS Light
这类"整体替换"，形状选择有限；SAM 生态权限严格、下载渠道不稳（社区经验）。

**HIMBO 的解法**是三件套（与 CBBE 同构）：

1. 一具覆盖人类/精灵/兽族的高模身体网格；
2. 一套 **126 个滑块**（含 4 个全身滑块），可在 BodySlide 或 RaceMenu 里调；
3. 一条**开放许可**（CC-BY-SA-4.0，可搬 Bethesda.net 只要不改名），
   让护甲作者敢把它做成默认支持。

> 完整机制（为什么拖滑块衣服跟着变、为什么要 Build Morphs）见
> [运行时 morph 与离线烘焙](morph-runtime-vs-bake.md)——男女两侧用的是同一套机制。

## 它包含什么

| 组件 | 说明 |
|---|---|
| 高模身体网格 | 人类/精灵/兽族成年男性；裸体 + 手 + 脚 |
| **全身滑块 ×4** | **Hugh**（胖，类比 SAM 的 Samuel）· **Hassan**（肌肉，类比 Samson）· **Hideo**（瘦，体重 0 时效果更明显）· **Hector**（接近 SOS 默认体型） |
| 附加滑块 | **Hank**（Gaz & Trivu 制作的另一版 Samuel 风格）、**Hayden**（女性化体型，拆成 4 个滑块）+ 一批 CBBE 灵感滑块；v5.0+ 合计 126 个 |
| 自带预设 | Daddy / Jack / Mike / Simple / Sultry / Chonky / Hassan / Hugh / Hideo / **Zero for OBody** / Urbon / Joseb / Sebastian |
| **SOS 版网格** | 带裆部开口，供 SOS addon 无缝接入；**默认预构建即此版** |
| **Nevernude 版** | 原版 Ragged Trousers 材质的四角裤；需自己在 BodySlide 里构建 |
| 物理版本 | 裸露（SOS）版附带 3 种物理配置，供 CBPC 或 HDT-SMP 使用 |
| UV 兼容性 | v4.0+ 与 SOS 型纹理、schlong addon、手脚替换全面互通 |

⚠️ 它**不包含**：皮肤纹理（推荐 BnP / Tempered Skins / Vitruvia）、
私密处网格（"The entire zip has no penis mesh"——作者原述）、
RaceMenu 框架、BodySlide 本身。

## 安装

### 步骤

1. **公共前置**：MO2、SKSE64、**XPMSSE**、[BodySlide and Outfit Studio](bodyslide-outfit-studio.md)。
   - 验证点：`Data\SKSE\Plugins\` 下有 XPMSSE 相关文件；MO2 工具里能跑起 BodySlide。
2. **装 HIMBO 主文件**（Nexus 46311）。
   - 验证点：BodySlide 的 Outfit/Body 下拉里出现 HIMBO 身体项。
3. **决定裸露版还是 Nevernude 版**：
   - 裸露（SOS）版 = 默认预构建，直接可用；
   - Nevernude 版 = 在 BodySlide 里构建对应选项获得（作者描述）。
4. **（可选）私密处框架**：装 **SOS** 或 **The New Gentleman**（Nexus 104215）。
   - 只在使用裸露版时需要；用 Nevernude 版则不需要（作者描述）。
   - 验证点：游戏内男性角色有对应网格；MCM 可调。
5. **（可选）物理**：装 [HDT-SMP](../04-physics/hdt-smp.md) + HIMBO 自带的物理版本
   （HDT-SMP 配置取自 HDT-BBB for SAM；CBPC 配置作者称测试中，暂未发布）。
6. **（可选）皮肤**：装男性皮肤的 **SOS-Lite / SOS 版**（见下文生态表）。
7. **构建**：BodySlide 里选 Outfit/Body = HIMBO 身体，选预设，**Batch Build**
   把同一预设刷给身体与所有 HIMBO 版护甲。
   - 验证点：构建列表里身体与每件护甲都在；缺的回去勾 Group Filter
     （**`Unassigned` 组必勾**，机制见 [morph-runtime-vs-bake.md](morph-runtime-vs-bake.md)）。
8. **（可选）NPC 分配**：装 [OBody NG](../05-distribution/obody-ng.md)，
   用 **HIMBO Zero for OBody** 做基础构建（见"使用与配置"）。

### FOMOD / 主文件选项

| 选项 | 选什么 | 备注 |
|---|---|---|
| 身体版本 | SOS（默认）/ Nevernude | 决定是否依赖私密处框架 |
| 物理版本 | 按需（HDT-SMP / CBPC / 无） | CBPC 配置作者称未完成 |
| 预构建网格 | SOS 版 | 想换 Nevernude 就自己构建 |

## 使用与配置

### BodySlide：形状从这里来

HIMBO 与 CBBE 一样**本体没有"最终形状"**，你看到的体型全部来自 BodySlide 构建：

```
Data\CalienteTools\BodySlide\SliderPresets\   ← 预设 .xml 放这里
```

- **男女骨骼不同**：社区指南（Return to Skyrim）的做法是打开 BodySlide 设置，
  确认当前骨骼对应性别——女性 `skeleton_female_sse.nif`、男性 `skeleton_male_sse.nif`，
  然后选身形、选预设、Batch Build（**社区经验**；该设置项在本库所用 BodySlide
  版本里的确切名称未能独立核实，以你实际界面为准）。
- **推荐工作流**：Zeroed Sliders 基准 + 运行时 morph，完整六步见
  [morph-runtime-vs-bake.md](morph-runtime-vs-bake.md)；
  HIMBO 侧直接有现成的 **HIMBO Zero for OBody** 预设可用。

### RaceMenu：那一栏滑块

三层来源：RaceMenu 框架 + HIMBO 的 morph 组件（决定有哪些滑块）+
你构建的 `.tri`（真正的变形数据）。滑块不出现时按
[racemenu-sliders-missing.md](../06-troubleshooting/racemenu-sliders-missing.md) 排。

### OBody NG：NPC 随机身材

RaceMenu 滑块**只作用于玩家**。NPC 分配用
[OBody NG](../05-distribution/obody-ng.md) / [RaceMenu BodyGen](../05-distribution/racemenu-bodygen.md)：
OBody 启动时扫描 `Data\CalienteTools\BodySlide\SliderPresets` 下的 XML 建库，
**HIMBO Zero for OBody** 就是为这个场景准备的（预设名即键，见
[bodyslide-presets.md](bodyslide-presets.md)）。

## 男性皮肤生态

男性皮肤与女性是**两条独立的链**（UV 不同、可选池不同）。常见组合：

| 用途 | mod | Nexus | 作者 |
|---|---|---|---|
| 人类男性皮肤 | **Vitruvia - Skin texture overhaul for males** | **SE 9112** / LE 82948 | mandragorasprouts |
| 人类男性皮肤 | **Tempered Skins for Males - Vanilla and SOS versions** | **SE 7902** | traa108 |
| 人类男性皮肤 | **BnP - Male Skin** | **SE 65402** | 基于 Vobla 的 Svein skin |
| 虎人男性皮肤 | Masculine Khajiit Textures (Grey Cat and Leopard) | **SE 186** | MONSTERaider（Grey Cat 原为 mrLenski） |
| 亚龙人男性皮肤 | Masculine Argonian Textures (Chameleon and Lizard) | LE 70164；**SE ID 未确认** | MONSTERaider |
| 男性皮肤（Norse 风） | SkySight Skins | **ID 未确认** | fadingsignal |
| HIMBO 预设 | Norse God -- HIMBO Bodyslide Preset | ID 未确认 | M4ruko |

> ⚠️ **反直觉但很重要：男性皮肤要下 SOS-Lite / SOS 版。**
> Return to Skyrim 指南（Nexus 58414）对 Vitruvia 与两个 MONSTERaider 皮肤
> 都写着同一句：
>
> "We need the **SOS version** even though we're not getting SOS,
> because it **meshes with HIMBO better**."
>
> 即：即使你不装 SOS，纹理也要选 SOS-Lite / SOS 版——v4.0 起 HIMBO 的 UV 与
> SOS 型纹理互通（作者描述），装原版（非 SOS）版本会出现接缝或错位。
> 这是**社区经验**（多个指南一致表述），与作者的 UV 说明互相印证。

## 与 SOS / TNG 的关系

**SOS（Schlongs of Skyrim）不是 HIMBO 的前置**，两者是"共用 UV 规范"的关系：

- **HIMBO 不含私密处网格**（作者原述："HIMBO is simply a MESH replacer.
  It does not add penises to your character at all."）；
  私密处相关问题请先修 SOS 本身，不要报给 HIMBO。
- v4.0+ HIMBO UV 与 SOS 纹理互通，任何 SOS 时代的纹理/schlong/手脚替换可直接使用；
  SOS 版 HIMBO 网格自带裆部开口，供 SOS addon 无缝接入。
- **SOS 的 SE 移植（galgaroth，LoversLab）自 2022-02 起宣布不再积极开发**；
  社区报告 SOS Full 的 DLL 在 SE 上检测 ESL/ESP-FE 有问题，动加载顺序会崩
  （LoversLab 帖，社区经验）。
- **The New Gentleman（TNG，Nexus 104215）**：SOS 的 2023 替代，作者 Novelyst
  （HIMBO 描述页点名 "The New Gentlemen by Novelyst and Modilogist"）。
  它是 CommonLib-NG 编写的 SKSE 插件，all-in-one（纹理 + 网格 + 私密处 + 插件），
  基于 Better Males 体型，**兼容所有 SOS Full retextures**，ESL 标记，
  默认 slot 32 护甲隐藏私密处，可用 `TNG_Revealing` / `TNG_Covering` 关键词
  或 `_TNG.ini` 逐件控制（Nexus 页描述，经转载）。

**选择建议**：想省事用 TNG；留在 SOS 生态用 SOS Full；
两者都不想装就构建 Nevernude 版 HIMBO。

## 兼容与冲突

| 关系 | 结论 |
|---|---|
| 护甲没有 HIMBO 版 | 角色**退回原版体型**（作者描述："using armors not made for HIMBO means your character will revert to vanilla body shape"） |
| 露手腕/脖子/脚踝的护甲 | 可能**出现网格缝隙**（作者描述明示的已知现象） |
| 女性身形（CBBE/3BA/BHUNP/UBE） | 两条独立链，**可同时启用**，互不覆盖 |
| 皮肤纹理 | 必须选 SOS 系 UV 版本（v4.0+ 互通）；原版（非 SOS）版会错位 |
| SOS / TNG | 二选一（或都不选 + Nevernude）；别同时装两套私密处框架 |
| 私密处护甲 slot | SOS/schlong 用 slot 52；TNG 默认 slot 32 隐藏——两者混用要查 MCM |

覆盖规则（谁的 nif 赢）见
[mo2-override-rules.md](../07-workflow/mo2-override-rules.md)。

## 排错

| 症状 | 判据 | 处理 |
|---|---|---|
| 男性角色还是原版方块身 | 没装 HIMBO，或护甲没有 HIMBO 版 | 装 HIMBO；找护甲的 HIMBO Bodyslide 文件并 Batch Build |
| 手腕/脖子/脚踝破皮、有缝 | 护甲非 HIMBO 化，裸露部位露出来 | 换 HIMBO 版护甲；这是作者明示的已知现象，裸露越多越明显 |
| 皮肤接缝/纹理错位 | 皮肤装的是非 SOS 系 UV 版本 | 改下 SOS-Lite / SOS 版（Vitruvia、Tempered、BnP Male Skin 均有） |
| 私密处不显示/隐形/穿帮 | HIMBO 不含私密处网格 | 装 SOS 或 TNG；SOS 的问题先按 SOS 页排查（作者原述） |
| RaceMenu 里没有 HIMBO 滑块 | 没勾 `Build Morphs`，或 Group Filter 漏勾 `Unassigned` | 按 [morph-runtime-vs-bake.md](morph-runtime-vs-bake.md) 工作流重做 |
| NPC 身材不随你调 / 不随机 | RaceMenu  morph 只作用于玩家 | 装 OBody NG，用 HIMBO Zero for OBody 做基础构建 |
| 物理不抖 | 没装物理版本或 HDT-SMP | 装 HIMBO 物理版本 + HDT-SMP；CBPC 配置作者称尚未发布 |
| 阴部区域网格扭曲（社区报告，v5） | 特定姿势/角度下的已知现象 | 社区经验（tesgeneral 汇总）；换角度或等后续版本，无官方修复确认 |

## 取舍与建议

**选 HIMBO 当你**：

- 你玩男性角色，或想让世界里的男性 NPC 不像方块人（配合 OBody NG）；
- 你要装的衣服/护甲 mod 带 HIMBO 文件（新 mod 的普遍形态）；
- 你在用整合包——主流清单的男性侧默认就是 HIMBO。

**注意**：

- **护甲适配是日常**：每换一个新护甲，优先找它的 HIMBO 版 Bodyslide 文件；
- **皮肤必须 SOS 系**：这是男性链与女性链最大的习惯差异；
- **裸露版依赖私密处框架**：不想碰 SOS/TNG 就构建 Nevernude 版。
