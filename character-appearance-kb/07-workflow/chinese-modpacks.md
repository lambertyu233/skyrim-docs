# 中文社区整合包现状

> ⚠️ **本条目整体可信层级偏低。** 整合包多发布在论坛帖与网盘，
> 缺少可长期引用的官方页面。**引用前请自行核对发布帖的最新版本。**
> 另：本条目的**主要价值反而是"证伪"** —— 见第二节。

> **一句话**：中文整合包从"安装程序"演化到"MOD 列表 + 教程"再到被 Wabbajack 取代，
> 但无论形态怎么变，**身形与物理层的四个结构性问题一个都没少**——
> 这也是为什么本库建议：评估任何整合包，都用本库的排错条目逐层验收。

## 速览

| 项 | 内容 |
|---|---|
| 条目性质 | 社区资源盘点 + **证伪**（三个查无实据的名字） |
| 已核实在维护 | **轮回**（SE/AE，V6.5，2026-08 更新，明确 3BA + FSMP + OAR） |
| LE 时代三大包 | 阳光（2014，臭皮匠组）/ 污神 / 无心 —— **均与 1.6.1170 不兼容** |
| 查无实据 | **九大猫 / 醉梦 / 陶德**（原样保留，勿当真实整合包） |
| 现代打底框架 | 绝伦（B站）/ 烽火神话（NGA 推荐）—— 社区经验 |
| 主要风险 | 构建产物、物理插槽、FaceGen 对齐（见"前世今生"） |
| 可信层级 | 整体偏低；引用前核对发布帖 |

要点：

- **"整合包"三个字不说明任何技术信息**：一个连身形与物理方案版本号都说不清的包，
  通常只是资源合集（实用结论第 2 条）。
- **本条目最值钱的是第二节**：三个被内容农场互相抄出来的"整合包名"，
  在照着名字去下载之前，**先怀疑它是否存在**。
- **无论用哪个包，本库排错条目都适用**：黑脸 / 脖缝 / 穿模 / 滑块缺失 / 物理不生效，
  这些症状不因"这是整合包"而豁免。
- **Wabbajack 类列表的可验证性远高于论坛网盘包**（判据见第三节与 [`wabbajack.md`](wabbajack.md)）。

## 前世今生

### 中文整合包的形态变迁

| 时代 | 分发形态 | 安装方式 | 可验证性 |
|---|---|---|---|
| **LE 时代（约 2011-2016）** | 3DM / 游侠等门户的 MOD 站 + 论坛帖 | **一键安装程序**或"解压复制进 Data"；绕开 NMM 直接物理写盘 | 低：版本冻结即报废，与 SE 完全不兼容 |
| **SE 初期（2016 之后）** | 论坛帖 + 网盘 | 仍常见"解压即玩"，少数开始附 NMM/MO2 说明 | 低：BSTriShape 换代后搬运 LE 资产一类就崩 |
| **MO2 普及后** | B 站 / NGA 帖 + 网盘 + 群文件 | 演化为"**MO2 mod 列表 + 图文教程**"，用户自己装 | 中：能看清装了哪些 mod，但版本靠人肉对齐 |
| **Wabbajack 时代（约 2020 之后）** | `.wabbajack` 文件 + 官方 Gallery | 指令清单自动复刻，版权文件从官方来源下载 | **高**：manifest 可查、可更新、可回滚 |

> 时间边界为社区通行说法（**社区经验**）；唯一起到锚点作用的一手事实是
> 阳光整合包 3DM 发布帖标注的 2014 年与轮回发布帖标注的 2026-08 更新。

### 为什么"一键整合"容易在身形/物理层出问题

这不是打包者的水平问题，而是**本库反复强调的四个结构原因**在整合包场景被放大：

1. **构建产物**：BodySlide 的输出（`.tri` + NIF 里的 `BODYTRI`）是**每台机器、
   每个预设下生成的**。整合包若不带预构建网格、又不给构建指引，
   用户拿到手就是"RaceMenu 里那一栏空的"（判据见
   [`../06-troubleshooting/racemenu-sliders-missing.md`](../06-troubleshooting/racemenu-sliders-missing.md)）；
   若带了预构建产物，它又极容易被包内后装的同名 nif 覆盖掉——
   覆盖关系在几百个 mod 的包里根本没人核（机制见
   [`mo2-override-rules.md`](mo2-override-rules.md)）。
2. **物理插槽**：SMP 与 CBPC **想挂同一批骨骼**，共存需要显式分腔配置
   （改 dll 名或改 `defaultBBPs.xml`）。这类"环境相关"的技巧在整合包里
   最难稳定复刻；身形还必须在 FOMOD 里选对 physics 变体（见
   [`../04-physics/physics-overview.md`](../04-physics/physics-overview.md)）。
3. **FaceGen**：NPC 的脸是**预生成网格**，与 head parts 记录必须一一对应。
   整合包含几十个 NPC 美化 mod 时，任何一层覆盖顺序错位就是**黑脸**
   （判据见 [`../06-troubleshooting/dark-face.md`](../06-troubleshooting/dark-face.md)）。
4. **版本冻结**：整合包出厂时锁定一组版本；上游 mod 一更新
   （或 Steam 一推送游戏更新），锁定的组合就可能整体失效。
   Wabbajack 列表用 manifest + hash 把这个问题变成"显式报错"，
   而网盘包只能变成"莫名的怪症状"。

> **一句话**：整合包能打包"文件"，很难打包"覆盖关系的正确性"。
> 后者恰恰是捏脸/身形系统的全部难点。

## 它解决什么问题

**没有整合包之前**：中文用户面对的是全英文的 Nexus、十几层依赖、
和大量已过期的机翻教程——整合包试图把"装不对"这个问题一次性解决。

**它的解法**是替用户做完全部决策：身形家族、皮肤、物理方案、NPC 美化全部预制。

**它自身的问题**则在于：封闭（用户不知道自己装了什么）、
不可验证（无 manifest、无 hash）、版本冻结（报废即整体报废）。
这三个问题正是 Wabbajack 的设计目标（见 [`wabbajack.md`](wabbajack.md)）。

## 一、确实存在且已核实的

### 阳光整合包（臭皮匠组）—— LE 时代

- 2014 年发布「《上古卷轴5》阳光环境、人物美化整合包 v1.3.3」，
  作者组「臭皮匠组」（一路阳光319、lwl612、ken890 等）。
- **针对老滚5传奇版 LE 1.9.32.0.8**，**不是 SE/AE**。
- 一个值得注意的设计思路：安装程序**彻底隔离 CBBE 与 UNP**，
  从安装层面杜绝"身形/皮肤选错" —— 这正对应
  [`../00-overview/ecosystem-map.md`](../00-overview/ecosystem-map.md) 里的互斥红线。
- 来源：3DM 发布帖 `https://bbs.3dmgame.com/thread-4500881-1-1.html` —— **社区经验（发布帖为真实一手，但版本为 LE）**

### 污神整合包 / 无心整合包 —— LE 时代

- 与阳光并列被称为经典三大整合包；无心更全（含武器/坐骑/衣服），但更复杂、需自行排序。
- **原始可靠来源缺失**（仅见于低质转载文），且同为 **LE 时代**。
- ⚠️ 即便存在，**与 1.6.1170 也不兼容**。

### 轮回整合包 —— SE/AE 时代，仍在维护

本次检索中**唯一明确使用 3BA 且仍在维护、对应 AE 时代**的国产整合包：

- 面向 **SE/AE 次世代**，迭代到 **V6.5（2026-08 更新）**；
- 自述"解压即玩"，内置前置、环境/人物/NPC 美化、装备、随从；
- 明确写「将整合的 **3BA 身形以及前置更新到最新**」「更新 **FSMP** 物理系统」「含 **OAR** 动作系统」；
- 提供「绅士版 / 正常版」切换。
- 来源：论坛发布帖 —— **社区经验（非官方站，路径/版本以发布帖为准）**

### 现代 SE 打底包

NGA 玩家推荐过的现代打底框架：**绝伦（B站「绝伦少年」）**、**烽火神话 / 神话**。
玩家评述是"适合做基础框架再填自己想要的 mod"、"神话完全不需要动手能力，照教程走"。
—— **社区经验（NGA 论坛）**

## 二、⭐ 三个查无实据的名字（不要把当真实整合包写进文档）

| 名字 | 核实结果 |
|---|---|
| **九大猫** | **未确认**。检索只返回 3DM 上的「**盒子猫服装整合**」（2017 服装/护甲 MOD，非整合包）。另：「9DM / 9大猫」是**站点名**，常被误当成整合包名 |
| **醉梦** | **未确认**。只命中内容农场站上一篇疑似 AI 生成的「梦里 / Dreamlike 整合包」文（宣称"全光追/16K 视差"等夸张内容），**无任何可靠来源** |
| **陶德** | **未确认**。只命中 3DM 上一个「托德·霍华德是我们的主人和救世主」的**玩笑 MOD**（音频/字体替换），非整合包 |

**这一节的意义**：这类名字往往来自内容农场互相抄写的"十大整合包"式文章。
在把它写进文档、或照着名字去下载之前，**先怀疑它是否存在**。

> 这三个名字与本条目的对应关系已同步记录在
> [`../08-sources/unreliable-and-unconfirmed.md`](../08-sources/unreliable-and-unconfirmed.md)
> 的"错误知识清单"里——两处口径一致，**都不要把它们写成真实整合包**。

## 三、给中文用户的实用结论

1. **LE 时代的整合包（阳光/污神/无心）与你无关** —— 版本不兼容，最多作历史参考；
2. **要找当代整合包，优先看是否明确写了 3BA / BHUNP + FSMP / CBPC 的版本号** ——
   一个连身形和物理方案都说不清的"整合包"，通常只是资源合集；
3. **Wabbajack 类自动安装列表的可验证性远高于论坛网盘整合包**
   —— 见 [`wabbajack.md`](wabbajack.md)；
4. 无论用哪个整合包，**本资料库的排错条目都适用**（黑脸/脖缝/穿模/物理不生效）。

## 使用与配置：拿到一个整合包后的检查清单

不管包来自论坛还是群文件，**装之前先做这四步**（判据来源：
[`../08-sources/unreliable-and-unconfirmed.md`](../08-sources/unreliable-and-unconfirmed.md) 的三条判据）：

1. **看它说不说版本号**：3BA / BHUNP / FSMP / CBPC / SKSE 的版本是多少？
   说不清的，按"资源合集"对待，不要按"调好的环境"对待。
2. **看它给不给文件路径与构建指引**：BodySlide 要不要你自己 Build？
   `Unassigned` 组勾没勾？没提构建的，进游戏第一件事就是查滑块那一栏是不是空的
   （见 [`../03-body/morph-runtime-vs-bake.md`](../03-body/morph-runtime-vs-bake.md)）。
3. **看它的 FaceGen 怎么处理**：含 NPC 美化的包，先问"黑脸了怎么修"，
   答案应该是覆盖关系排查而不是"重装"（见 [`../06-troubleshooting/dark-face.md`](../06-troubleshooting/dark-face.md)）。
4. **看它的更新与回滚机制**：有发布帖持续维护（如轮回）比一次性网盘包可信；
   有 manifest/hash（Wabbajack）又比发布帖可信。

**装之后的验收动作**与本库学习路径完全一致：
能进 RaceMenu 且看到身形滑块 → 拖滑块身体会变 → 穿衣服不破皮 →
走动有物理 → 进城看 NPC 身材不同。任何一步不过，**回对应条目排错，
而不是回帖问"为什么"**（路径见 [`../00-overview/learning-path.md`](../00-overview/learning-path.md)）。

## 排错

| 症状 | 判据（看到 X 说明是 Y） | 处理 |
|---|---|---|
| 进游戏是原版捏脸界面 | 包内 RaceMenu 未启用 / SKSE 版本不对 | 查左栏启用状态与版本（[`../02-face/racemenu.md`](../02-face/racemenu.md)） |
| 身形滑块那一栏没有或为空 | 没构建 `.tri`，或构建产物被覆盖 | 自己跑 Zeroed Sliders + Build Morphs + Batch Build（[`../06-troubleshooting/racemenu-sliders-missing.md`](../06-troubleshooting/racemenu-sliders-missing.md)） |
| NPC 黑脸 | head parts 与 FaceGen 对不上（覆盖顺序错位） | 按两栏一致性排查（[`../06-troubleshooting/dark-face.md`](../06-troubleshooting/dark-face.md)、[`mo2-override-rules.md`](mo2-override-rules.md)） |
| 身体/头发完全不抖 | 非 physics 变体 / 没构建 / 两个引擎抢插槽 | 见 [`../06-troubleshooting/physics-not-working.md`](../06-troubleshooting/physics-not-working.md) |
| 裸体好、穿衣服穿模 | 服装没参与 Batch Build / 家族不匹配 | 见 [`../06-troubleshooting/clipping.md`](../06-troubleshooting/clipping.md) |
| Steam 更新后整合包整体报废 | 版本锁定被打破 | 回滚游戏版本或等包更新；版本决策见 [`../00-overview/game-version-1-7-x.md`](../00-overview/game-version-1-7-x.md) |

## 取舍与建议

- **不想学任何东西**：选一个明确标注 3BA + FSMP + 仍在维护的当代包
  （轮回是本次检索中唯一符合的），或直接用 Wabbajack 列表。
- **想保留"知道自己装了什么"的能力**：用现代打底框架（绝伦/神话一类）
  + 本库学习路径自己填内容。
- **想最大可验证性**：Wabbajack——manifest 可查、hash 校验、失败显式报错。
- **无论选哪条**：把 [`install-order.md`](install-order.md) 的"分层验收"当作
  整合包的验收单——整合包改变了"装"的成本，没有改变"验"的必要。
