# Valhalla Combat——无脚本战斗大修（dTry，停更）

## 一句话

官方描述原文："a modular, consistent, and script-free combat overhaul"——精力重制 + 无脚本计时格挡/弹反投掷物 + 眩晕处决。**注意：韧性（poise）系统在其描述里是 "(Planned)"，从未实装**【一手源】。

## 作者勘误

**作者是 dTry（D7ry），不是 Dieny**。GitHub：[D7ry/valhallaCombat](https://github.com/D7ry/valhallaCombat)【一手源】。

## 机制要点【一手源】

- 精力回复 5 倍速、命中轻击回精力、耗尽进入 Exhaustion（玩家减半伤害 / NPC 不能攻击）。
- 无脚本**计时格挡**（timed block）与**弹反投掷物**。
- 眩晕值 + 处决（类似 AC:Valhalla / God of War）。

## 现状

- **停更**：v1.2 更新说明自述 "No update for the newest AE update, but should work with older versions of AE"，最后实质更新停留在 2022 年【一手源】。
- AE 1.6.1170 的用户靠社区补丁（dTry 系列 AE 补丁 Nexus 85740）【社区经验】。
- 与 [Elden Parry](../05-block-parry/elden-parry.md) 有官方联动（Valhalla 更新后 Elden Parry 可对 NPC 追加眩晕伤害）；[MaxsuPoise](./maxsu-poise.md) 推荐开它的 Block Stamina + Guard Break 搭配使用【一手源】。
