# Elden Rim——艾尔登战技（战斗大修 + 动作包）

## 一句话

官方描述原文（作者中文）："艾尔登战技是一个战斗大修模组，拥有完整的技能体系，特殊硬直动画，按键触发，法术框架，韧性机制和熟练度系统……大部分功能基于原版架构，因此它稳定且兼容性良好"——不只是动作包，是一整套法环风战斗系统。

## 基本事实【一手源】

- Nexus [mods/65625](https://www.nexusmods.com/skyrimspecialedition/mods/65625)，作者 "black achang"（Black / black364 与 Achang 团队）。
- **仍在活跃更新**：v3.7.5（2026-09-26，新增战意 UI）。
- **框架双支持**：作者明确写 "I recommend you to use MCO with 1.5.X or BFCO"——MCO 与 BFCO 都能用。
- 社区反馈**最新版硬性要求 Maxsu 的 [Modern Stagger Lock](../04-poise/modern-stagger-lock.md)**【一手源，ER Katana 页面回帖】。

## 配套包

- **ADXP I MCO elden rim moveset collection (SCAR)**：[mods/72220](https://www.nexusmods.com/skyrimspecialedition/mods/72220)（black364，MCO+OAR+SCAR 硬性，2024-08 更新）——NPC 可用的 ER 风连招动作合集。
- 同作者还有 WoLong、ER Katana、ER Rapier 系列包 → 见 [其他动作包](./misc-movesets.md)。
