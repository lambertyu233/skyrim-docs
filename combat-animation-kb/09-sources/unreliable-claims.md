# 常见错误说法、查无此物与作者勘误

以下每条都经官方渠道（GitHub 仓库 / Nexus 发布页 / 作者回帖）核实，标注证据等级。**本工作区来源纪律的总纲见 [skyrim-tools-kb/12-sources/unreliable-sources.md](../../skyrim-tools-kb/12-sources/unreliable-sources.md)。**

## 查无此物（名称讹传）

- **"Elden Dodge"**：Nexus 查无此独立 mod，Maxsu 的 GitHub 也无此仓库。最接近的存在是 **Elden Ring Step Dodge**（mods/64248，作者 skypia/Smooth）与 **Elden Rim dodge**（mods/76868 系，TK Dodge RE 动画替换）【一手源】。
- **"TK Dodge Ultimate"**：不存在此独立 mod——是 TK Dodge + Ultimate Combat 套装的混称【一手源】。
- **"Skypia 系列"**：查无此作者。Aramusha/Nobushi 实为 **lSmoothl 的 For Honor in SKYRIM 单角色包**（现已并入 AIO）【一手源】。
- **"SoulCalibur moveset"**：Nexus 查无同名 moveset 页面（只有武器模型 mod），可能为 Patreon/Discord 发布【未核实】。
- **"DM-IIO"**：查无此 TDM 附属 mod；TDM 的知名附属是 TrueHUD 与 Dodge Framework【未核实，疑为记忆混淆】。

| BDI 是 Dtry 写的 | **Maxsu and Dropkicker**（Nexus 页 Created by 原文） | 【一手源】 |
| AMR 是 Maxsu 写的 | **alexsylex**（Maxsu 仅在致谢中提供过汇编帮助） | 【一手源】 |
| Modern Stagger Lock 是 Dtry 写的 | **Maxsu**（GitHub max-su-2019） | 【一手源】 |
| Valhalla Combat / Elden Parry / Elden Counter 是 Maxsu 写的 | 均为 **dTry（D7ry）** | 【一手源】GitHub |
| iFrame Generator RE 是 Sokkvabekk 写的 | **Maxsu**（AE 版 doodlum） | 【一手源】 |
| Dual Wield Parrying NG 维护者是 alandtse | 1.6.1130+ 代码由 **moshikle** 写（文件页原文）；alandtse 只是 CommonLibSSE-NG 库作者之一 | 【一手源】 |
| ABR = Attack Behavior Replacer | 实为 **Attack Behavior Revamp** | 【一手源】 |

| MCO 原页 mods/124806 可引用 | 该页已 **Removed by staff**；现行官方页为 **mods/175044**（2026-03 重传，v1.6.0.6 终版） | 【一手源】 |

## 站点与信息源警示

- **distaranimation.com**（Distar 官网）：抓取已被解析到无关垃圾页面（疑似域名失效/被劫持），其上的 "SkySA Guide / MCO 教程" 内容**不可引用**，一律以 Nexus 页为准【未核实具体原因，但内容不可用】。
- "DMK 是 BFCO 3.100 硬前置"的说法仅见于作者授权中文镜像 magicskyrim 的前置清单；Nexus 正文只在 FAQ 提 dTry's Key Utils——两层说法并存，**以 Nexus 正文为准**【一手源+社区经验】。
- 内容农场（CSDN、toolify 等）转载的动作教程**版本号与前置清单错漏百出**，本库一律不采；工具领域的不可信来源清单见 [skyrim-tools-kb/12-sources/unreliable-sources.md](../../skyrim-tools-kb/12-sources/unreliable-sources.md)。
