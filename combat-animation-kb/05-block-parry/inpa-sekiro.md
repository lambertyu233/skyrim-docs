# Inpa Sekiro Combat——只狼式战斗大修（老 mod）

## 一句话

官方描述原文："This is a revolutionary project that overturns the boring Vanilla combat system to Sekiro system"——架势（posture）条、弹反/招架、危险攻击、忍杀处决。

## 基本事实【一手源】

- 作者 Inpa Skyrim；Nexus [mods/41428](https://www.nexusmods.com/skyrimspecialedition/mods/41428)。
- **v2.2.3（2021-07-24）后停更**，是 Papyrus 脚本系大修，页面 Requirements 无 MCO/OAR/AMR 等现代框架——**不依赖 MCO/BFCO**。
- 硬性前置：moreHUD SE、**Spell Perk Item Distributor（SPID）**、VioLens；HUD 部分另需 SkyHUD、MoreHUD、FISS。
- 官方兼容补丁只有 Ultimate Combat 与 Zxlice BackStab and Parry 两个。

## 与 BFCO 的关系【未核实】

官方页面**未声明 BFCO 兼容性**。架构上其架势逻辑与动画框架无关，但动画层面与改 1hm_behavior 的框架（BFCO/MCO）需要用户自行测试。社区普遍反馈其脚本负载较高、前置必须装齐。

## 提醒

只狼系玩法在现代组合里的替代路线：架势条可用 [MaxsuPoise](../04-poise/maxsu-poise.md) 系，弹反可用 [Elden Parry](./elden-parry.md) + [Elden Counter](./elden-counter.md)——都还在维护。
