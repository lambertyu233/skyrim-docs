# DMCO——Dodge MCO（反应最快的闪避）

## 一句话

Distar（MCO 作者）系的闪避 mod，基于 **Ersh 的 Dodge Framework**；官方原话 "The most reactive dodge mod. … Snappy and elegant"，闪避攻击可直接过渡进 MCO 攻击链。**BFCO 官方 description 明确 "Fully compatible with DMCO (any version)"**——BFCO 玩家的默认闪避选择。

## 基本事实

- 全名 **"Dodge - MCO (DMCO)"**，描述自称 "Dodge MCO-DXP"；MCO 指 Distar 自家的 Modern Combat Overhaul，**不是** "Dodges Mod - Combat Overhaul"【一手源】。
- 现行 Nexus 页 [mods/175129](https://www.nexusmods.com/skyrimspecialedition/mods/175129)（官方站点 distaranimation.com/mods/dodge——注意该域名抓取曾异常，引用以 Nexus 为准）。
- 框架作者 Ersh，后由 doodlum、EliasReplay 维护【一手源】。
- 最新 v2.1.21（2026-03-20，AE 1.6.640 支持）【一手源】。

## 硬性要求（mods/175129 Requirements）【一手源】

- **Behavior Data Injector + BDI Universal Support**
- **IFrame Generator RE（+AE Support）**——见 [IFrame Generator](./iframe-generator.md)
- **MCO Universal Support**
- **Pandora 或 Nemesis**（二选一）
- AE 1.6.1130+ 另需 Hellblade Timed Block AE Support

是否硬性要求装 MCO 主框架：新页面未写死，闪避攻击过渡到 MCO 属"完整体验"项【未核实】。

## 注意

- 与 TK Dodge 系互斥（同类功能）——见 [TK Dodge 家族](./tk-dodge-family.md)。
- 需要 MCO 攻击链的（闪避攻击）才联动 MCO；纯闪避独立工作。
